# media

Imágenes públicas de todos los proyectos (posts de LinkedIn, Instagram de Sur Padel).
Se sirven por raw.githubusercontent.com para Buffer. No borrar archivos ya publicados o programados.

- `img/` — posts de LinkedIn
- `surpadel/` — piezas de Sur Padel programadas en Buffer
- `instagram/` — campañas de Instagram de Sur Padel ya publicadas (movidas desde la web el 2/11/2026)

La carpeta `instagram/overgrip` sigue en el repo de la web porque la escribe la automatización de OverGrip.
